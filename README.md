## Features & Funktionen

- **KI-Finanzanalyse:** Automatische Erfassung und Auswertung von Ausgaben.
- **Budgetverwaltung:** Übersichtliche Verwaltung von Einnahmen, Ausgaben und Budgets.
- **Benutzerfreundliches UI:** Moderne, intuitive Benutzeroberfläche für eine einfache Bedienung.
